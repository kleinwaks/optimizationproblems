# The two-set sum-difference exponent

## Description of constant

$C\_{3f}$ is the infimum of exponents $\\lambda$ such that, for all finite nonempty sets $X,Y$ of integers, $\rvert X-Y\rvert\le\rvert X+Y\rvert^\\lambda$.


## Known upper bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $3/2$ | [GHR2007] | |
| $\frac{9451e−3286}{5378e+787} = 1.45427744\dots$ | [K2026] | Holds for sets in any abelian group. |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $\log{(1+\sqrt 2)}/\log{2} = 1.27155\dots$ | [HRY1999], [GHR2007] | Take X=Y in the projected high-dimensional simplex construction. |

## Additional comments

The constant is distinct from $C\_{3e}$, which restricts to $X=Y$, and from $C\_{3a}$, which imposes small doubling. [K2026] proves $C\_{3a} ≤ 2−1/C_{3f}$.
